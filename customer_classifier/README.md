# 고객 문의·리뷰 자동 분류 프로그램

LGE.COM CS 전략 과제 — Ollama 로컬 LLM + Amazon Redshift

## 빠른 시작

```bash
# 1. 라이브러리 설치
pip install -r requirements.txt

# 2. (DB 사용 시) 접속 정보 설정
cp .env.example .env
# .env 파일을 열어 실제 값 입력

# 3. Ollama 실행 및 모델 다운로드 (별도 터미널)
ollama serve
ollama pull exaone3.5

# 4. 프로그램 실행
streamlit run app.py
```

## 파일 구조

```
customer_classifier/
├── app.py              # 메인 Streamlit 앱 (4단계 워크플로우)
├── classifier.py       # Ollama LLM 분류 엔진 + 규칙 사전분류
├── report_builder.py   # 전략 추출용 집계 리포트 생성기
├── pii.py              # 개인정보 마스킹 모듈
├── data_loader.py      # 파일·DB 데이터 로딩
├── db_connector.py     # Redshift 연결 모듈
├── utils.py            # 공통 유틸리티
├── requirements.txt    # 필요 라이브러리
├── .env.example        # 접속 정보 템플릿
└── .gitignore
```

## 워크플로우 (4단계)

1. **데이터 입력** — 파일 업로드 또는 Redshift 직접 연결
2. **분류 실행** — 실패수요 / 가치수요 / 기타 / 판단보류 자동 분류
   - ⚡ **규칙 사전분류**: 배송지연·환불오류·시스템오류·파손·호환성 등 아주 명백한
     표현은 LLM 없이 규칙으로 즉시 분류 → 사양 낮은 PC에서 LLM 호출량·시간 절감
   - 소형 모델 대응: 결정적 출력(temperature=0), JSON 강제(format=json),
     출력 길이 제한, 모델 상주(keep_alive)로 파싱 실패율·속도 개선
3. **결과·검토** — 차트·세부분류 순위 확인, 사람이 직접 수정 (출처=규칙/LLM 구분)
4. **전략 리포트** — 분류 결과를 **개인정보 마스킹된 집계 리포트(.md)**로 변환

## 전략 추출 (Claude 프로젝트 연계)

무거운 종합·추론은 로컬 소형 모델 대신 **Claude 프로젝트**(또는 사내 승인 LLM)에서
수행합니다. 4단계에서 생성한 리포트는:

- 원문 전체가 아닌 **집계 + 대표 인용문**만 담아 외부 반출 데이터를 최소화
- 모든 인용문의 **개인정보를 마스킹**(전화·이메일·주소·카드·주문번호·이름)
- 각 인용문에 추적용 `[ID]` 부여 → LLM이 근거를 지목·추적 가능

리포트(.md)를 Claude 프로젝트 지식에 올리고, 함께 제공되는 `지침(.txt)`을
커스텀 인스트럭션에 넣은 뒤 **① Pain Point → ② 근본원인 → ③ 개선과제 →
④ 우선순위** 순서로 단계적으로 대화하면 전략 과제를 도출할 수 있습니다.

> ⚠️ 규칙 기반 마스킹은 완벽하지 않습니다. 외부 반출 전 리포트를 훑어보고,
> 사내 데이터 반출 정책(외부 AI 서비스 업로드 허용 여부)을 반드시 확인하세요.

자세한 사용법은 프로그램 실행 후 **도움말** 탭을 참고하세요.
